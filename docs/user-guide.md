# User Guide

## Installing FUSKAMO
Install from the Google Play Store (or TestFlight/App Store once iOS is set up) like any other app.

## Submitting a player
Tap the **+** tab, fill in the required fields (name, position, age, country), optionally attach a short video clip, and submit. Submissions are reviewed before appearing in the public feed.

## Browsing
Use the filter chips at the top of the Feed to narrow by position or age group. Use Discover to browse by region.
