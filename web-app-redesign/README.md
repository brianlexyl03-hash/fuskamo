# FUSKAMO Web — Upgraded Dashboard

This is the redesigned web shell built on top of the existing FUSKAMO web implementation.

## What is actually wired
- Approved player loading, search and filtering via the existing Supabase player query.
- Team loading via the existing Supabase teams query.
- Live counters for players, teams, scouts and countries.
- Existing player/team/club/coach/scout registration modals and insert flows are preserved.

## What is UI-first
Groups, messaging, reels, stories and the Scout Desk surfaces are deliberately presented as dashboard modules without pretending their backend is complete.
